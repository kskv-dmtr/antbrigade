# ant brigade

Витрина личной коллекции музыки: обложки, жанры, лейблы и ссылки на площадки.
Живёт по адресу [antbrigade.fun](https://www.antbrigade.fun), исходники — в
[репозитории](https://github.com/kskv-dmtr/antbrigade).

Сайт статический. Ни базы, ни сервера приложений: содержимое лежит в Notion,
раз в час выгружается в JSON, из него собирается около трёх тысяч готовых
страниц, и Vercel раздаёт их файлами.

```
Notion  →  data/albums.json  →  Astro  →  dist/*.html  →  Vercel
        ↑                    ↑
   раз в час              обложки и кадры
   бот в CI               лежат рядом, в public/
```

## Быстрый старт

```bash
npm install
npm run dev      # локально, http://localhost:4321
npm run build    # собрать в dist/
npm run doctor   # что в базе не заполнено и что рассыпалось
```

Подробности запуска, выгрузки и выкладки — в `README.md` в корне репозитория.
Здесь, в этих заметках, — про устройство: что из чего собрано и почему именно
так.

## Как это читать

Заметки описывают **устройство**, `README` — **действия**. Если вопрос
начинается с «как мне…» — это в `README`. Если с «почему оно…» или «где
лежит…» — сюда.

Отдельно стоит [[Решения]]: там перечислены места, которые выглядят как
недосмотр, но сделаны намеренно, и варианты, которые уже рассматривались и
отпали. Перед тем как «поправить» что-то странное или предложить «очевидное»
улучшение, стоит заглянуть туда.

**Правило ведения:** в конце каждой сессии принятые и отклонённые решения
дописываются в [[Решения]] — с причиной и числами. Не в переписку и не в
сообщение коммита: читать будут отсюда.
